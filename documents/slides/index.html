How it works

The page
site's own JS
Calls fetch, canvas, WebGL, audio, navigator…
Detector
main/detector.js
Wraps those APIs in the page's own world. Notes which script called. Rewrites probes when protecting.
Bridge
isolated/bridge.js
Relays events to the service worker. Nothing else.
Inference
background/inference.js
Pure function. Probed IDs → traits. Three API families in five seconds → fingerprint.
The card
popup/
Plain words. One button. Per-site protection kept in local storage.
Manifest V3, natively

Dynamic content scripts and a module service worker. No remote code.

Nothing blocked on the network

Probe URLs point at an extension that doesn't exist; the browser itself says "not installed".

Nothing leaves the device

No server, no account, no model. The extension makes zero requests of its own.
